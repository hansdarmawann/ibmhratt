### Ready-to-paste PR description

## Objective

Prepare an explicitly selected AutoML candidate and require provenance/data checks plus documented
owner review before serving it. Preserve the previous bundle for verified atomic rollback.

## Scope and files changed

- Add prepare/review/activate/rollback CLI and behavioral integration tests.
- Support candidate development evidence in API/dashboard without claiming holdout scores.
- Document staging checks, approval, maintenance and rollback; update changelog and ignored local state.

## Design and compatibility

- Existing behavior preserved: baseline train/search/evaluation and reports, schema-2 integrity and
  pointer format, prediction responses and optional serving dependencies.
- New interface: `python -m attrition.models.promotion [--models-dir PATH]` with explicit trial,
  search/nested evidence and manual approval.
- ML/data boundary: OOF F2 threshold and final fit use only original training rows. No holdout scoring,
  new search or automatic highest-AP activation. Nested evidence assesses a development procedure,
  not the particular fitted candidate.

## Security / responsible use

Trusted operator paths/UUIDs only; no HTTP artifact-path interface. Approval binds manifests and
the prior pointer and requires reviewer/reason plus source/serving evidence. Approval files are
not signatures. Fictional/synthetic data only; individual employment decisions remain prohibited.

validates the receipt and expected current run, atomically restores the prior pointer, and deletes
nothing. Restart API and rerun dashboard; verify the restored UUID and predictions.
