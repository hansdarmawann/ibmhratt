- Known risks and unresolved owner decisions:
  - **Error-format change:** 422 entries no longer include `input` or `ctx`, and at most 100 are listed. Clients that read those fields would break. Record this in the changelog (PR 10) and decide on the version bump.
  - With a key configured, requests without it now get 401 even when the body is malformed (previously 422). An oversized request that declares its length gets 413 before the key check. That reveals only the size limit.
  - `MAX_BODY_BYTES` (8,192,000) is a code constant, adjustable through `create_app(max_body_bytes=...)` but not through the environment. Exposing it as an environment variable is an owner decision.
  - `Cache-Control: no-store` applies to every response, including `/docs`.
  - `KeyCheckedRoute` uses FastAPI's documented `APIRoute.get_route_handler` extension point and `route.dependencies` (FastAPI pinned at 0.142.2). The behavior tests catch a regression on upgrade, and the dependency still enforces the key if the early check is ever skipped.
  - Docker was not exercised locally; the Dockerfile is unchanged. External read-only mounts and extra runtime flags are documented as untested.
  - Tests that train in a deep temp directory on Windows can hit the 260-character path limit (pre-existing; see Full pytest).
