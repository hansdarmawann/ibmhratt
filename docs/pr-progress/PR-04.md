## Acceptance criteria
- [x] Integrate Optuna with **existing sklearn preprocessing pipelines**, applying all learned transforms within each CV training fold. Reuse existing feature schema/validation and seed conventions.
- [x] Search **logistic regression**, **random forest**, and **histogram gradient boosting** initially; treat a dummy classifier as a non-tuned reference if appropriate.
- [x] Use *conditional* parameter spaces appropriate to each estimator. Avoid invalid solver/penalty combinations and overly broad ranges on the small dataset.
- [x] Default primary optimization score: **average precision (AP)**, estimated solely by stratified training-fold CV.
- [x] Start with 5 folds, seeded sampler (e.g. Optuna `TPESampler(seed=...)`), serial execution (`n_jobs=1`) for reproducibility, and configurable trial/time budget; recommend about 30 trials/900 seconds for manual experiments, not CI.
- [x] Provide an explicit opt-in command such as `python -m attrition.models.automl --n-trials 30 --timeout 900 --seed 42`.
- [x] Keep baseline `python -m attrition.models.train` unchanged; add no implicit AutoML or retraining during imports or app startup.
- [x] Never read or touch holdout labels, generate final holdout scores, update `models/current.json`, or publish model bundles as a side effect of a search trial.
- [x] Add unit tests with tiny synthetic data and a 1–2 trial deterministic smoke test. Bound trial runtime and resources.
- [x] Make Optuna optional (`requirements-automl.txt`, appropriate extras, or another repo-consistent mechanism). If a lock file is authoritative, update it consistently. Do not add Optuna to serving images unnecessarily.

§4 AutoML gates covered by this PR: tiny deterministic smoke test [x]; preprocessing within CV folds [x]; holdout cannot reach the optimizer [x] (no threshold selector exists in this PR); baseline CLI outputs and served pointer unchanged [x] (static: no baseline file changed; baseline training not re-run); seed and fold configuration recorded [x]; large experiments opt-in [x].
